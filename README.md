## 👨‍💻 About Me

I build products that hold up in production. With 4+ years of experience, I've shipped web platforms, event-driven microservices, Shopify apps, and high-conversion e-commerce applications.

I enjoy the hard middle of the stack: Kafka pipelines, BullMQ workers, Postgres schemas that stay fast, and interfaces that feel instant.

- 🔭 **Building:** a personal brand site and scalable full-stack products
- ⚙️ **Day to day:** TypeScript, Next.js, Node.js, Laravel, PostgreSQL
- 🧠 **AI features:** pgvector, LangChain, OpenAI and Gemini APIs for semantic search and LLM-powered tools
- 🚢 **Shipping:** Docker on Linux servers with CI/CD through GitHub Actions
- 🌱 **Currently learning:** Kubernetes, AWS, monitoring and observability
- 🤝 **Open to:** collaborating on open source and product work
